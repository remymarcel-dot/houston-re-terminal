Data Feeds · Going Live

the upgrade path from inbox-scan to real-time metro coverage
RentCast APIFree 50 calls/mo · dev ~$74/mo

Property records, value + rent AVMs, and active-listing feeds for all Houston zips. Best price/performance first key to acquire — powers live comps and rent checks per deal.

FEMA NFHL APIFree

Flood-zone lookup by address. Non-negotiable in Houston — 5 zips in this book (77339, 77079, 77026, 77077, 77539) sit in flood-history areas. Auto-flag every new deal.

HCAD Parcels API — CONNECTED ✓Free · no key · live since Jul 23

Harris County appraisal roll via the public ArcGIS REST service (gis.hctx.net): land/building/total values, owner, class — per address. Run hcad_lookup.py <num> <street> [zip]. Already killed the Montridge "comps" (developer land assemblage, same owner both lots). Harris Cty only — Fort Bend/Galveston deals need their own CAD.

HAR MLS via SimplyRETS / Trestle~$49–99/mo + broker sponsor

The real live feed: every new listing, price change, pending and sold in the metro, minutes after it hits MLS. Needs a sponsoring agent/broker — ask Dillon or Nate to sponsor your data access.

ATTOM DataEnterprise (from ~$500/mo)

Deeds, foreclosure/pre-foreclosure, distressed-owner signals — find off-market deals before the wholesalers do.

Rentometer Pro API~$99/mo

Address-level rent comps to sanity-check every rental underwrite against real asking rents.

Zillow (Bridge Interactive)Gated / free if approved

Zestimate + rental Zestimate API. Approval takes weeks — apply early, use RentCast meanwhile.

PropStream / BatchLeads~$99–150/mo

Not an API but the standard investor lead engine: liens, probate, absentee owners across the metro — build your own deal flow instead of waiting on blast emails.
